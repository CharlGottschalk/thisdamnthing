The Dryft design system

Is my data hosted anywhere?{{ faqSign0 }}
No. The workspace is a directory on a machine you control. There is no tenancy and no phone-home.
Do I need a stack to start?{{ faqSign1 }}
No. The OS registers projects, runs Doctor and keeps records on its own. Add a stack when you want one.
Can I write my own stack?{{ faqSign2 }}
Yes, against the same public contract first-party stacks use. There is no private path.
05 — Rules

How to keep it satin

Do
One gold element per viewport. If two compete, one of them is decoration.
Let surfaces do the separating — border hairlines over shadows.
Keep body copy at 16.5 and lines under 62 characters.
Use Geist Mono only for real machine output: paths, commands, ids.
Don't
No purple-to-magenta gradients. The base is one flat colour.
No glowing shadows in the accent hue. Satin has no bloom.
Never put gold text on the base — only gold fills with dark text.
No third accent. Coral and gold is the whole budget.
