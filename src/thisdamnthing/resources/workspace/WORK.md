# Work conventions

This file contains your filing preferences. Edit it directly or ask the agent to update
it. These preferences do not grant permission to execute commands or change unrelated
files.

All internal working files live under `work/`. Paths below are relative to it.
Create directories only when needed. Preserve existing files.

## Projects

Default to `<project-name>/`, using readable lowercase hyphen-separated names.
If the request and existing preferences do not specify a location, ask whether the
project should be internal or external.
For external projects, ask for the directory; keep existing projects in place.

## Notes and reminders

Core scratchpad notes use `notes/` and reminders use `reminders/`. These folders
are created on first save. Keep project files in separate locations.

## Other working files

Use the location requested by the user. When no convention covers a new type of
work, suggest a simple location and ask. Do not create unused starter folders.

## Precedence

The current request takes precedence. When continuing existing work, use its
actual location. Apply these conventions to new work before stack suggestions.
Changing conventions does not relocate existing files or projects.
